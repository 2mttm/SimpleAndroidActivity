# CryptoInfo App

**CryptoInfo** — это Android-приложение, созданное в рамках лабораторной работы по дисциплине "Программирование для мобильных платформ" (ПАМ). Приложение предоставляет пользователю актуальную информацию о криптовалютах, возможность поиска новостей и мини-игру с push-уведомлением.

## 📱 Функциональность

Приложение включает в себя следующие основные функции:

- **Список криптовалют:** отображение основных криптовалют с их текущими ценами и изменением за последние 24 часа.
- **Детальный просмотр:** при выборе криптовалюты отображается подробная информация с интерактивным графиком цены за 60 дней.
- **Поиск новостей:** встроенный браузер открывает сайт [BeInCrypto](https://beincrypto.com/) с результатами поиска по введённому запросу.
- **Мини-игра и push-уведомление:** игра на время, в которой нужно нажимать на цель. После окончания игры пользователь получает push-уведомление с результатами.

## 🧩 Используемые компоненты UI

- `EditText` для ввода поискового запроса  
- `Button` для активации поиска, запуска игры и переходов  
- `ListView` для отображения списка криптовалют  
- `NotificationManager` для отправки push-уведомления  
- Веб-интент для открытия встроенного браузера  

## 🚀 Как использовать

1. Введите ключевое слово в текстовое поле и нажмите кнопку поиска — откроется браузер с результатами.
2. Выберите криптовалюту из списка — откроется окно с подробной информацией.
3. Нажмите на кнопку запуска игры — сыграйте и получите уведомление с результатами.

## 🛠️ Технологии

- Java / Android SDK  
- API для получения информации о криптовалютах  
- Встроенные Android-компоненты: `Intent`, `Notification`, `ListView`, `Activity`, `Timer`
- **MPAndroidChart** — библиотека для построения графиков
